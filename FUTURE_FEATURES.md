# Future Features

## Planned

- **IQ-TREE phylogenetics (or other)**: Maximum-likelihood phylogenetic tree inference from nucleotide and amino acid alignments produced by the pipeline (MAFFT outputs).
- **RepeatMasker**: Repeat masking of assemblies using a user-provided consensus FASTA file (e.g., a custom repeat library).
- **Orthofinder**: Orthology inference across multiple assemblies, including clustering of orthologous groups and generation of gene trees. Use BUSCO genes
- **Visualizations**: Quality stats, assembly metrics, TE landscapes, etc.
